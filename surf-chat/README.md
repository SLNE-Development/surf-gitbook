# Willkommen bei surf-chat

surf-chat stellt ein vollständiges Chat-Management-System für Paper-Server bereit. Es unterstützt verschiedene Nachrichtentypen, ein mehrstufiges Verarbeitungssystem mit Chat-Prozessoren, automatische Moderation, eine Ignore-Liste sowie einen durchsuchbaren Nachrichtenverlauf.
